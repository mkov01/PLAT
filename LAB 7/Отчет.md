# 📊 ОТЧЕТ ПО ЛАБОРАТОРНОЙ РАБОТЕ №7
> **Тема:**  Создание простого одностраничного приложения (SPA) без фреймворков: навигация по вкладкам, динамическая подгрузка контента
>

> 
> **Среда разработки:** Visual Studio Code / HTML5, CSS3, JavaScript (ES6)  

---

## Номер и условия вариантов
**Задание №4** (Базовый уровень):  SPA «Кафе». Требуется реализовать одностраничный интерфейс со вкладками «Меню», «Акции», «Адреса». Карточки блюд на вкладке меню должны генерироваться динамически, выводя данные из предопределенного массива объектов JavaScript. Активная вкладка должна визуально выделяться с помощью CSS.

**Задание №11** (Средний уровень): SPA «Магазин». Требуется разработать интерфейс с вкладками «Товары», «Корзина», «О магазине». Необходимо реализовать бизнес-логику динамического пересчета и отображения количества добавленных товаров в корзине в реальном времени.

**Задание №18** (Повышенный уровень): SPA «Панель заказов». Требуется реализовать систему управления заказами с вкладками «Новые», «В работе», «Готовые». Скрипт должен динамически изменять статус заказов (переносить записи между разделами), а также в режиме реального времени обновлять счетчики количества заказов на самих кнопках вкладок.

---

## Цель работы

Освоить построение одностраничных веб-приложений (SPA) на чистом JavaScript без использования сторонних фреймворков. Научиться организовывать клиентскую маршрутизацию (навигацию) по вкладкам, перехватывать и обрабатывать события кликов через addEventListener(), динамически управлять содержимым контейнеров посредством манипуляций с DOM, хранить и обновлять состояние приложения (бизнес-логику) непосредственно в JavaScript-объектах.

---

## Входные и выходные данные

### Задание №4 (Базовый уровень):
**Входные данные:**  Событие клика пользователя по кнопкам навигации («Меню», «Акции», «Адреса»). Data-атрибуты кнопок (data-page). Предопределенный массив объектов с блюдами.

**Выходные данные:**  Динамическая генерация карточек блюд из массива объектов на странице меню. Изменение текстового контента на других страницах. Переключение CSS-класса активного состояния .active на выбранной вкладке.

### Задание №11 (Средний уровень):
**Входные данные:**  Событие клика на кнопки «Добавить в корзину» в каталоге товаров. Событие клика на кнопку «Очистить корзину». Переключение на вкладку «Корзина».

**Выходные данные:**  Изменение внутренней переменной состояния счетчика. Динамический рендеринг содержимого вкладки «Корзина» с актуальным выводом количества выбранных товаров.

### Задание №18 (Повышенный уровень):
**Входные данные:** Массив объектов (заказов) с уникальными ID и статусами. События кликов по кнопкам смены статуса («В работу», «Завершить») внутри карточек заказов.

**Выходные данные:** Изменение свойства status у объекта в массиве, мгновенная перерисовка текущего экрана, пересчет количества элементов для каждой группы и обновление числовых индикаторов (счетчиков) на кнопках вкладок.

---

## Алгоритм решения

1. **Разметка интерфейса (HTML5):**
	• Создать общую адаптивную сетку-дашборд из трех независимых карточек компонентов для одновременной демонстрации всех трех SPA-вариантов (4, 11, 18).
	• Внутри каждого компонента спроектировать изолированную навигационную панель (<nav>) со вкладками, содержащими data- атрибуты, и целевой контейнер <main> для отрисовки динамического контента.

3. **Оформление и интерактивные состояния (CSS3):**
	• Описать стили интерфейса с использованием современных CSS-переменных.
	• Сформировать класс .active для кнопок вкладок (изменение фона, цвета текста и нижней рамки), визуально подтверждающий пользователю текущую локацию внутри SPA.
	• Настроить плавные переходы (transition) для интерактивных элементов.

4. **Сценарии JavaScript-валидации:** 
	• • Изоляция модулей: Код каждого варианта обернут в отдельный логический блок для предотвращения пересечения глобальных переменных.
• Вариант №4: Создан массив объектов menuItems, где у каждого блюда есть название, цена и описание. При активации страницы «Меню» скрипт с помощью цикла или метода .map() динамически создает HTML-карточки для каждого объекта. Другие страницы подгружают статичные строки.
• Вариант №11: Заведено реактивное состояние количества товаров (cartCount). На вкладке товаров генерируются интерактивные кнопки. Метод добавления инкрементирует значение переменной. При переходе на вкладку корзины шаблон формируется динамически на основе текущего значения cartCount.
• Вариант №18: Создан локальный массив объектов, имитирующий базу данных заказов. Навигационные кнопки содержат динамические контейнеры под счетчики. Функция updateCounters() пробегает по массиву фильтрами .filter(o => o.status === '...') и обновляет текст на кнопках. При клике на кнопку изменения статуса у заказа меняется поле состояния, после чего вызывается комплексный метод render(), обновляющий и контент, и счетчики на вкладках.

## 🎯 Вывод

В ходе выполнения лабораторной работы были успешно освоены архитектурные концепции построения Single Page Applications (SPA) на чистом JavaScript (Vanilla JS). Реализована динамическая маршрутизация контента на основе событийных моделей без перезагрузки страниц и отправки лишних HTTP-запросов на сервер. Были отработаны практические навыки декларативного связывания данных, управления состояниями объектов (счетчики корзины, динамические статусы задач) и манипулирования CSS-классами для интерактивного отклика интерфейса на действия пользователя.
