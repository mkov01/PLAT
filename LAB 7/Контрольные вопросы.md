## 🧠 Контрольные вопросы и ответы

**Ответ №8:** **SPA (Single Page Application)** — это одностраничное веб-приложение, которое загружает единственный HTML-документ и динамически обновляет его содержимое по мере взаимодействия с пользователем.

* **Главное отличие:** В классическом многостраничном сайте (MPA) любой клик по ссылке инициирует полноценный HTTP-запрос к серверу, который генерирует и возвращает абсолютно новую страницу, вызывая визуальное мерцание и перезагрузку. В SPA переходы происходят мгновенно на стороне клиента за счет манипуляций с DOM-деревом с помощью JavaScript.
</details>

<summary><b>9. Как переключать вкладки без перезагрузки страницы?</b></summary>
<br>

**Ответ №9:** Переключение организуется с помощью **перехвата событий клика** на элементы навигации (кнопки или ссылки). При срабатывании события скрипт:
1. Блокирует стандартное поведение браузера (если используются ссылки — через `event.preventDefault()`).
2. Определяет целевую вкладку (например, считывая ее идентификатор из `data-` атрибута).
3. Динамически очищает или заменяет содержимое главного контейнера страницы (`main.innerHTML = newContent`).
</details>

<details>
<summary><b>10. Как найти и изменить элемент DOM?</b></summary>
<br>

**Ответ №10:** 
* **Поиск элементов:** Выполняется с помощью современных методов `document.querySelector('селектор')` (возвращает первый найденный элемент) или `document.querySelectorAll('селектор')` (возвращает статическую коллекцию `NodeList` всех совпадений). Также используются классические методы вроде `document.getElementById('id')`.
* **Изменение элементов:** Осуществляется через перезапись их внутренних свойств, таких как `.textContent` (для текста), `.innerHTML` (для HTML-структур), `.className` / `.classList` (для управления стилями) или `.style.свойство` (для инлайнового CSS).
</details>

<details>
<summary><b>11. Зачем нужен addEventListener()?</b></summary>
<br>

**Ответ №11:** Метод `addEventListener()` используется для **регистрации обработчика события** на целевом DOM-элементе. Он позволяет гибко реагировать на действия пользователя (клик, ввод текста, отправка формы, нажатие клавиш). 

* **Преимущество:** В отличие от устаревших инлайновых атрибутов (например, `onclick="..."` прямо в HTML), этот метод разделяет разметку и логику, позволяет вешать несколько разных обработчиков на одно и то же событие одного элемента, а также поддерживает тонкую настройку (фазы перехвата, однократное срабатывание `once` и т.д.).
</details>

<details>
<summary><b>12. Для чего используются data-атрибуты?</b></summary>
<br>

**Ответ №12:** Пользовательские `data-*` атрибуты предназначены для **хранения произвольных незаметных данных** непосредственно в HTML-разметке элемента. Они позволяют связать интерфейс с бизнес-логикой JavaScript. 

*Пример из проекта:* тег `<button data-page="contacts">` хранит строковое значение целевого раздела. В JavaScript доступ к этим данным получается мгновенно через объектное свойство элемента `.dataset.page`.
</details>

<details>
<summary><b>13. Чем textContent отличается от innerHTML?</b></summary>
<br>

**Ответ №13:** 
* `textContent` работает **строго с сырым текстовым содержимым** узла. Если передать в него строку `<strong>Привет</strong>`, браузер отобразит ее на экране именно в таком виде, экранируя спецсимволы. Это безопасно и защищает приложение от XSS-атак (внедрения вредоносного кода через инпуты).
* `innerHTML` парсит переданную строку как **полноценный HTML-код**, создавая внутри DOM-дерева новые дочерние элементы и теги. Используется для динамической генерации сложной верстки из скрипта.
</details>

<details>
<summary><b>14. Как выделить активную вкладку?</b></summary>
<br>

**Ответ №14:** Выделение активной вкладки реализуется путем **динамического управления CSS-классами**:
1. В CSS-файле описывается класс активного состояния (например, `.tab-btn.active { color: #3b82f6; border-bottom: 2px solid #3b82f6; }`).
2. В JavaScript-обработчике клика при переключении сначала запускается цикл `.forEach()`, который удаляет класс `active` у абсолютно всех кнопок навигационной панели.
3. Затем к элементу, по которому непосредственно кликнул пользователь (`event.currentTarget`), точечно добавляется этот класс: `element.classList.add('active')`.
</details>

<summary><b>15. Как организовать данные нескольких разделов?</b></summary>
<br>

**Ответ №15:** Для чистой архитектуры Vanilla SPA данные разделов структурируют в виде **JavaScript-объектов или коллекций**:
* **Для статичного контента:** Создается единый конфигурационный объект, где ключами выступают названия страниц (`data-page`), а значениями — шаблоны строк разметки.
* **Для динамического контента:** Данные хранятся в виде массивов объектов (например, реализованный в Варианте 4 массив `menuItems` или в Варианте 18 массив `orders`), а финальный HTML-код генерируется «на лету» с помощью методов массивов `.map()` или `.forEach()` при активации конкретной вкладки.
</details>

<summary><b>16. Что делает fetch() и почему локальные файлы могут не загружаться через file://?</b></summary>
<br>

**Ответ №16:** 
* `fetch()` — это современный встроенный интерфейс для отправки **асинхронных сетевых запросов** к серверу по протоколу HTTP/HTTPS и получения ресурсов (например, JSON или HTML файлов) без перезагрузки текущей страницы.
* **Проблема локального запуска (`file://`):** Если вы пытаетесь сделать `fetch('data.json')`, открыв HTML-файл двойным кликом в браузере (в адресной строке будет `file:///C:/...`), запрос заблокируется встроенной политикой безопасности браузера **CORS (Cross-Origin Resource Sharing)**. Браузер считает протокол `file://` небезопасным окружением, у которого нет четкого понятия «источника» (Origin), и запрещает локальное чтение соседних файлов. Для обхода этого ограничения проект обязательно нужно запускать на локальном веб-сервере (например, через плагин *Live Server* в VS Code), чтобы файлы раздавались по адресу `http://localhost:...`.
</details>

<details>
<summary><b>17. Как обработать ошибку загрузки данных?</b></summary>
<br>

**Ответ №17:** При использовании `fetch()` обработка ошибок строится на комбинации **проверки свойства `response.ok` и блока `.catch()`** в цепочке промисов или конструкции `try...catch` при `async/await`:

```javascript
async function loadData() {
    try {
        const response = await fetch('data.json');
        if (!response.ok) {
            throw new Error(`Ошибка сервера: ${response.status}`);
        }
        const data = await response.json();
        renderContent(data);
    } catch (error) {
        console.error("Сбой загрузки:", error);
        document.getElementById('content').innerHTML = `
            <div class="error-msg">⚠️ Не удалось загрузить данные. Пожалуйста, повторите попытку позже.</div>
        `;
    }
}
```
</details>

<summary><b>18. Как проверить доступность навигации с клавиатуры?</b></summary>
<br>

**Ответ №18:** Доступность (Accessibility / a11y) проверяется без использования мыши:
1. Нажмите клавишу **Tab** сразу после загрузки страницы. Фокус должен последовательно и визуально понятно перемещаться по всем интерактивным кнопкам вкладок слева направо.
2. Элементы навигации должны быть семантическими (теги `<button>` или ссылки `<a>`), так как они по умолчанию включены в фокус клавиатуры. Если используются `<div>`, им нужно принудительно задать атрибут `tabindex="0"`.
3. При нажатии клавиши **Enter** или **Space (Пробел)** на сфокусированной вкладке должно происходить полноценное переключение контента, аналогичное стандартному клику мыши.
</details>

<summary><b>19. Какие преимущества и ограничения имеет SPA без фреймворков?</b></summary>
<br>

**Ответ №19:**

| Критерий | Преимущества (Vanilla SPA) | Ограничения |
| :--- | :--- | :--- |
| **Производительность** | Максимальная скорость работы. Нет тяжелого оверхеда библиотек (React/Vue), код весит минимально. | При разрастании кодовой базы без компонентного подхода код превращается в трудночитаемую «лапшу» (*Spaghetti-код*). |
| **Сборка проекта** | Не требуются сложные инструменты (Webpack, Vite, npm), проект работает прямо «из коробки». | Приходится вручную следить за очисткой памяти, удалением старых обработчиков событий и перерисовкой каждого узла. |
| **SEO и Маршрутизация**| Идеально подходит для локальных микро-сервисов и понимания базы веб-стандартов. | Из коробки отсутствует поисковая оптимизация и работа кнопок браузера «Назад/Вперед» (требуется подключать *History API*). |
</details>
