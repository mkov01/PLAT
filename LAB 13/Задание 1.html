1. Обоснование выбора структуры данных

Для реализации списка покупок выбран список (list), элементами которого являются словари (dict) или строки названий. Список сохраняет порядок добавления товаров, поддерживает быстрое добавление в конец (append() за O(1)), перебор всех элементов для просмотра и удаление по значению/названию. Для дополнительной функции отмены последнего действия (Undo) используется принцип стека (LIFO) на базе списка history_stack.

2. Исходный код на Python (lab13.py — Вариант 1)

def add_item(shopping_list, item_name):
      name = item_name.strip()
      if not name:
          print("Ошибка: название товара не может быть пустым.")
          return False
      if any(x.lower() == name.lower() for x in shopping_list):
          print(f"Предупреждение: товар '{name}' уже есть в списке.")
          return False
      shopping_list.append(name)
      print(f"Товар '{name}' добавлен.")
      return True
  
  def remove_item_by_name(shopping_list, item_name):
      if not shopping_list:
          print("Ошибка: список покупок пуст, удалять нечего.")
          return False
      target = item_name.strip().lower()
      for item in shopping_list:
          if item.lower() == target:
              shopping_list.remove(item)
              print(f"Товар '{item}' удалён из списка.")
              return True
      print(f"Ошибка: товар '{item_name}' не найден в списке.")
      return False
  
  def show_all_items(shopping_list):
      if not shopping_list:
          print("Список покупок пуст.")
          return
      print("Текущий список покупок:")
      for idx, item in enumerate(shopping_list, start=1):
          print(f"{idx}. {item}")
  
  if __name__ == "__main__":
      cart = []
      add_item(cart, "Молоко")
      add_item(cart, "Хлеб")
      show_all_items(cart)
      remove_item_by_name(cart, "Сыр")     # Обработка отсутствующего товара
      remove_item_by_name(cart, "молоко")  # Удаление без учёта регистра
      show_all_items(cart)

3. Ответы на контрольные вопросы

Чем список (list) отличается от словаря (dict)?

Список — это упорядоченная коллекция с доступом по целочисленному индексу (0, 1, 2...), а словарь хранит пары «ключ: значение» с быстрым доступом по уникальному ключу (в среднем за O(1)).

Что означают LIFO и FIFO?

LIFO (Last In, First Out) — последним пришёл, первым ушёл (принцип стека). FIFO (First In, First Out) — первым пришёл, первым ушёл (принцип очереди).

Как реализовать стек на Python и как безопасно извлечь из него элемент?

Стек реализуется обычным списком с методами append() (положить) и pop() (извлечь). Перед вызовом pop() нужно проверить, не пуст ли стек (if stack:), чтобы избежать ошибки IndexError.

Почему collections.deque удобен для очереди?

В обычном списке удаление первого элемента pop(0) работает за O(n), так как сдвигает все остальные элементы. В двусторонней очереди deque метод popleft() выполняется за O(1).

Что произойдёт при обращении к отсутствующему ключу словаря?

При обращении через d[key] возникнет исключение KeyError. Для безопасного доступа используют метод d.get(key, default) или проверку if key in d:.
