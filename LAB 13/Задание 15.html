1. Обоснование выбора структуры данных

Для мини-библиотеки выбран вложенный словарь (dict) вида library[book_id] = {"title": ..., "author": ..., "available": True}. Ключом выступает уникальный идентификатор книги (ID), что обеспечивает поиск, выдачу и возврат книги за $O(1)$ без полного перебора коллекции. Для получения списка доступных книг используется генератор списка по значениям словаря ([b for b in library.items() if b["available"]]), а для отмены действий — стек истории LIFO.

2. Исходный код на Python (lab13.py — Вариант 15)

def add_book(library, book_id, title, author):
    if book_id in library:
        print(f"Ошибка: книга с ID '{book_id}' уже существует.")
        return False
    library[book_id] = {
        "title": title,
        "author": author,
        "available": True,
        "reader": None
    }
    print(f"Книга [{book_id}] '{title}' добавлена в библиотеку.")
    return True

def issue_book(library, book_id, reader_name):
    if not library:
        print("Ошибка: библиотека пуста.")
        return False
    book = library.get(book_id)
    if book is None:
        print(f"Ошибка: книга с ID '{book_id}' не найдена.")
        return False
    if not book["available"]:
        print(f"Отказ: книга '{book['title']}' уже выдана читателю {book['reader']}.")
        return False
    book["available"] = False
    book["reader"] = reader_name
    print(f"Книга [{book_id}] '{book['title']}' выдана читателю {reader_name}.")
    return True

def return_book(library, book_id):
    book = library.get(book_id)
    if book is None:
        print(f"Ошибка: книга с ID '{book_id}' не найдена.")
        return False
    if book["available"]:
        print(f"Предупреждение: книга '{book['title']}' уже находится в библиотеке.")
        return False
    book["available"] = True
    book["reader"] = None
    print(f"Книга [{book_id}] '{book['title']}' возвращена в библиотеку.")
    return True

def get_available_books(library):
    available = {bid: info for bid, info in library.items() if info["available"]}
    if not available:
        print("Нет доступных книг для выдачи.")
    else:
        print("Доступные книги:")
        for bid, info in available.items():
            print(f"  {bid}: {info['title']} — {info['author']}")
    return available

if __name__ == "__main__":
    lib = {}
    add_book(lib, "B001", "Изучаем Python", "Марк Лутц")
    add_book(lib, "B002", "Грокаем алгоритмы", "Адитья Бхаргава")
    get_available_books(lib)
    issue_book(lib, "B001", "Алия")
    issue_book(lib, "B999", "Дамир")  # Обработка несуществующего ID
    get_available_books(lib)
    return_book(lib, "B001")

3. Ответы на контрольные вопросы

Когда стоит использовать dict вместо list?

Словарь (dict) стоит использовать, когда у каждого элемента есть уникальный идентификатор (ключ — например, ID книги, артикул или ИИН) и требуется мгновенный поиск, обновление или удаление записи по этому ключу за $O(1)$.

Что такое вложенный словарь?

Это словарь, значениями которого являются другие словари (например, library["B001"] = {"title": "...", "available": True}). Он позволяет структурировать несколько атрибутов для одного объекта.

Что произойдёт при обращении к отсутствующему ключу словаря?

Прямое обращение library["B999"] вызовет исключение KeyError. Чтобы избежать падения программы, применяют безопасный метод library.get("B999") или проверку if "B999" in library:.

Как определить сложность операций добавления и поиска?

В словаре dict (реализованном на основе хеш-таблицы) поиск по ключу, вставка и удаление в среднем выполняются за константное время $O(1)$. В списке list поиск по значению требует линейного прохода $O(n)$.
