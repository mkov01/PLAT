1. Обоснование выбора структуры данных

Для моделирования истории браузера используются два стека (LIFO) на базе списков Python: back_stack и forward_stack, а также переменная current_url для хранения текущей открытой страницы. Принцип LIFO (Last In, First Out) идеально подходит для навигации, так как кнопка «Назад» всегда возвращает пользователя на самую последнюю посещённую страницу (вершину back_stack за $O(1)$ через pop()). При переходе по новому URL стек forward_stack очищается методом clear(), чтобы исключить несогласованные ветки истории.

2. Исходный код на Python (lab13.py — Вариант 17)

class BrowserHistory:
      def __init__(self, homepage="https://portal.edu.kz"):
          self.current_url = homepage
          self.back_stack = []
          self.forward_stack = []
  
      def visit(self, url):
          clean_url = url.strip()
          if not clean_url:
              print("Ошибка: пустой URL.")
              return False
          if clean_url == self.current_url:
              print(f"Вы уже находитесь на странице {clean_url}")
              return False
          self.back_stack.append(self.current_url)
          self.current_url = clean_url
          self.forward_stack.clear()  # Обязательная очистка истории вперёд
          print(f"Переход на: {self.current_url}")
          return True
  
      def back(self):
          if not self.back_stack:
              print("Ошибка: история 'Назад' пуста.")
              return None
          self.forward_stack.append(self.current_url)
          self.current_url = self.back_stack.pop()
          print(f"Назад -> {self.current_url}")
          return self.current_url
  
      def forward(self):
          if not self.forward_stack:
              print("Ошибка: история 'Вперёд' пуста.")
              return None
          self.back_stack.append(self.current_url)
          self.current_url = self.forward_stack.pop()
          print(f"Вперёд -> {self.current_url}")
          return self.current_url
  
  if __name__ == "__main__":
      browser = BrowserHistory("https://google.com")
      browser.visit("https://python.org")
      browser.visit("https://github.com")
      browser.back()                        # Вернётся на python.org
      browser.visit("https://wikipedia.org") # Очистит forward_stack
      browser.forward()                     # Выведет, что история 'Вперёд' пуста

3. Ответы на контрольные вопросы

Что означают LIFO и FIFO?

LIFO (Last In, First Out) — последним пришёл, первым ушёл (стек). FIFO (First In, First Out) — первым пришёл, первым ушёл (очередь).

Как реализовать стек на Python и безопасно извлечь элемент?

Стек строится на обычном списке list с помощью методов append() и pop(). Перед вызовом pop() обязательно проверяют if stack:, чтобы избежать исключения IndexError при пустом стеке.

Зачем при переходе по новому URL очищать forward_stack?

Когда пользователь нажал «Назад» и открыл новую ссылку, создаётся новая ветка навигации, поэтому прежние страницы из ветки «Вперёд» становятся неактуальными и удаляются через forward_stack.clear().

Какова сложность операций push и pop в стеке?

Обе операции (append() и pop() с конца списка) выполняются за амортизированное константное время $O(1)$.
