## 📐 СЛАЙД 2: Задание №2 — Прямоугольник
> **Условие:** Введите длину и ширину прямоугольника. Найдите площадь и периметр.

<details>
<summary><b>🔍 Посмотреть разбор слайда (Алгоритм и математика)</b></summary>

* **Входные данные:** `a` (длина), `b` (ширина) \(\in \mathbb{R}^+\)
* **Формулы:** 
  * Площадь: \(S = a \times b\)
  * Периметр: \(P = 2 \times (a + b)\)

</details>

```python
# Фрагмент кода
S = a * b
P = 2 * (a + b)
print(f"Площадь: {S:.2f} | Периметр: {P:.2f}")
```

#### 🖥️ Демонстрация работы (Тест 1):
```text
Введите длину: 5.5
Введите ширину: 4
-----------------------------------------------------
✔ Результаты вычислений:
  • Площадь (S) : 22.00
  • Периметр (P): 19.00
```

## 🔢 СЛАЙД 3: Задание №10 — Поразрядный разбор
> **Условие:** Введите четырехзначное число. Выведите его цифры по отдельности: тысячи, сотни, десятки и единицы.

<details>
<summary><b>🔍 Посмотреть разбор слайда (Целочисленная математика)</b></summary>

Для выделения разрядов используются операторы `//` (деление нацело) и `%` (остаток от деления):
* **Тысячи:** `num // 1000`
* **Сотни:** `(num % 1000) // 100`
* **Десятки:** `(num % 100) // 10`
* **Единицы:** `num % 10`

</details>

```python
# Чисто математический разбор без строк
thousands = num // 1000
hundreds = (num % 1000) // 100
tens = (num % 100) // 10
units = num % 10
```

#### 🖥️ Демонстрация работы (Тест 2):

  • Сотни   : 5
  • Десятки : 6
  • Единицы : 7

## 📈 СЛАЙД 4: Задание №17 — Капитализация вклада
> **Условие:** Введите сумму вклада, годовую ставку и количество лет. Рассчитайте итоговую сумму при ежегодной капитализации.

<details>
<summary><b>🔍 Посмотреть разбор слайда (Финансовая математика)</b></summary>

* **Формула сложных процентов:** 
  \[A = P \times \left(1 + \frac{r}{100}\right)^n\]
* Где: \(P\) — вклад, \(r\) — процентная ставка, \(n\) — количество лет.

</details>

```python
# Финансовый расчет
amount = principal * ((1 + rate / 100) ** years)
profit = amount - principal
```
