> **Тема:**  Продвинутые манипуляции с DOM в JavaScript: создание элементов, управление CSS-классами, обработка сложных событий и валидация.

## Номер и условия вариантов
**Задание №3** (Базовый уровень): Список покупок. Требуется реализовать графический интерфейс для добавления элементов списка из текстового поля. Клик по пункту должен переключать состояние элемента (визуальное зачеркивание). У каждого элемента должна быть кнопка удаления.

**Задание №10** (Средний уровень): FAQ-Аккордеон. Требуется разработать интерфейс раскрывающихся блоков «Вопрос-Ответ». При клике на заголовок отображается скрытый текст. Должна быть реализована бизнес-логика: одновременно открытым может оставаться только один блок.

**Задание №16** (Повышенный уровень): Мини-игра «Поймай объект». Требуется реализовать интерактивную область, внутри которой круглый объект случайно перемещается после каждого успешного клика по нему. Скрипт должен осуществлять математический расчет случайных координат с учетом границ контейнера и фиксировать очки.

---

## Цель работы

Освоить продвинутые методы работы с объектной моделью документа (DOM) с использованием JavaScript. Научиться динамически создавать и удалять узлы DOM-дерева, гибко управлять CSS-классами для динамического изменения визуального состояния интерфейса,
организовывать безопасную обработку пользовательского ввода, рассчитывать геометрические координаты элементов и применять паттерны остановки всплытия событий (stopPropagation).

---

## Входные и выходные данные

### Задание №1 (Базовый уровень):
**Входные данные:** Текстовая строка из поля ввода (название товара). Событие клика на кнопку «Добавить» или нажатие клавиши Enter. Событие клика на кнопку «Удалить».
**Выходные данные:** Появление нового элемента списка внутри контейнера <ul>. При клике на элемент — переключение CSS-класса .completed (зачеркивание текста). При клике на кнопку «Удалить» — полное удаление узла из структуры страницы.

### Задание №11 (Средний уровень):
**Входные данные:** Событие клика пользователя на интерактивный заголовок панели с вопросом.
**Выходные данные:** Плавное раскрытие блока с ответом за счет изменения высоты CSS-сетки (grid-template-rows), поворот индикатора + / −, а также автоматическое закрытие и сброс состояния у всех остальных панелей аккордеона.


### Задание №20 (Повышенный уровень):
**Входные данные:** События кликов по перемещающемуся круглому объекту внутри игровой зоны. Событие клика на кнопку «Играть заново».
**Выходные данные:** Мгновенный математический пересчет и изменение инлайновых стилей style.left и style.top объекта для перемещения в случайную точку. При достижении 10 очков — вывод экрана победы и блокировка игры.

---

## Алгоритм решения

1. **Разметка интерфейса (HTML5):**
	• Сформировать общую сетку-дашборд (Grid Layout), разделяющую рабочую область на три независимые карточки компонентов.
	• Использовать семантические теги и атрибуты доступности (aria-expanded, role="region", role="checkbox") для соответствия профессиональным стандартам веб-разработки.

3. **Оформление и интерактивные состояния (CSS3):**
• Описать интерактивные состояния элементов (:hover, :active, :focus-within) и добавить плавные переходы (transition).
• Для аккордеона применить современный подход плавной анимации высоты от нуля до авто-размера с помощью grid-template-rows: 0fr и 1fr, что исключает баги верстки.
• Использовать абсолютное позиционирование для игрового объекта внутри изолированного контейнера position: relative.

4. **Сценарии JavaScript-валидации:** 
	• Изоляция контекста: Обернуть каждый программный модуль в самовызывающуюся функцию (IIFE), чтобы изолировать области видимости переменных и исключить конфликты в глобальном пространстве.
	• Модуль списка покупок (Задание №1): Валидация строки методом .trim(). Безопасная генерация узлов через document.createElement() и .textContent для защиты от XSS-атак. Применение event.stopPropagation() на кнопке удаления, чтобы клик по ней не вызывал ложное срабатывание зачеркивания строки.
	• Модуль FAQ-Аккордеона (Задание №11): Навешивание события на общий контейнер. При клике определять целевую кнопку через метод .closest(), считывать текущее состояние класса .is-open. Сбрасывать класс у всех элементов в цикле forEach и точечно открывать только выбранный кликнутый элемент.
	• Модуль мини-игры (Задание №20): Использование функции getBoundingClientRect() для получения точных динамических размеров игрового поля и объекта. Расчет максимальных доступных координат maxX = viewportWidth - targetWidth. Генерация случайной позиции с помощью Math.random() и округления Math.floor(), благодаря чему объект гарантированно не вылетает за границы поля. Контроль достижения лимита очков и переключение экранов интерфейса.

## 🎯 Вывод

В ходе выполнения лабораторной работы №6 были успешно изучены и применены на практике продвинутые концепции объектной модели документа (DOM) и событийно-ориентированного программирования на языке JavaScript (стандарт ES6+).
1. Глубокая работа со структурой документа: Освоены методы динамического конструирования многоуровневых узлов страницы с помощью document.createElement(). Внедрение текстового пользовательского ввода (название и цена товара) реализовано строго через свойство textContent, что полностью исключает возможность проведения XSS-атак (межсайтового скриптинга).
2. Управление сложными событиями: На практике применен метод event.stopPropagation(), позволивший изолировать событие удаления дочерней кнопки от клика по родительскому элементу списка. Реализован перехват контекста с помощью метода .closest() для динамического переключения состояний CSS-классов.
3. Анимации и геометрия: Разработаны адаптивные интерфейсные решения, включая плавную CSS Grid анимацию раскрытия скрытых панелей через манипуляцию grid-template-rows. На примере мини-игры закреплены навыки считывания точных метрик контейнеров через getBoundingClientRect(), а также генерация случайных величин при помощи математических функций Math.random() и Math.floor().
