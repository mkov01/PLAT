## 📂 Structure & Contents

### [9] Что такое JSON и чем он отличается от объекта JavaScript?
* **JSON (JavaScript Object Notation)** — это текстовый формат обмена структурированными данными.
* **Отличие от объекта JS:** JSON является строкой, поддерживает только базовые типы данных, не содержит методов (функций) и требует обязательного использования двойных кавычек для ключей.

### [10] Для чего нужны JSON.stringify() и JSON.parse()?
* `JSON.stringify()` — преобразует объект или массив JavaScript в строку JSON для записи в хранилище.
* `JSON.parse()` — выполняет обратную десериализацию строки JSON в объект или массив JS.

### [11] Почему localStorage хранит строки?
* Архитектура Web Storage API спроектирована для хранения данных в виде пар «ключ-значение», где оба элемента являются строками (`DOMString`)[cite: 2].

### [12] Чем localStorage отличается от sessionStorage?
* `localStorage` — сохраняет данные между перезапусками браузера и сессиями в пределах источника[cite: 2].
* `sessionStorage` — хранит данные исключительно в рамках текущей сессии вкладки браузера[cite: 2].
