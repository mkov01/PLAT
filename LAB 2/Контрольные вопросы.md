## Контрольные вопросы

**1.** Что представляет собой переменная в Python?
Переменная — это имя, которое используется для хранения значения в памяти программы.

**2.** Какие основные типы данных используются в Python?
Основные типы: int — целые числа, float — дробные числа, str — строки, bool — логические значения.

**3.** Чем int отличается от float?
int используется для целых чисел, а float — для чисел с плавающей точкой, то есть дробных чисел.

**4.** Как работает функция input()?
Функция input() получает данные, введенные пользователем с клавиатуры, и возвращает их в виде строки.

**5.** Почему результат input() часто необходимо преобразовывать?
Потому что input() всегда возвращает строку (str), а для выполнения математических операций необходимо преобразовать её в числовой тип.

**6.** Для чего используются int() и float()?
int() преобразует значение в целое число, а float() — в число с плавающей точкой.

**7.** Чем / отличается от //?
Оператор / выполняет обычное деление и возвращает результат с дробной частью. Оператор // выполняет целочисленное деление, отбрасывая дробную часть.

**8.** Что делает оператор %?
Оператор % возвращает остаток от деления одного числа на другое.

**9.** Для чего используется оператор **?
Оператор ** используется для возведения числа в степень.

**10.** Как определить тип переменной с помощью type()?
Необходимо передать переменную в функцию type(), например:
type(x)
Функция вернет тип данных переменной.

**11.** Что такое преобразование типов?
Преобразование типов — это изменение типа данных одного значения в другой, например преобразование строки в целое число с помощью int().

**12.** Что произойдет при попытке int("Python")?
Произойдет ошибка ValueError, потому что строку "Python" невозможно преобразовать в целое число.

**13.** Как получить последнюю цифру целого числа?
С помощью оператора %:
num % 10

**14.** Как удалить последнюю цифру целого числа?
С помощью целочисленного деления на 10:
num // 10

**15.** Почему выбор правильного типа данных важен?
Правильный выбор типа данных позволяет корректно хранить и обрабатывать информацию, выполнять необходимые операции и избегать ошибок в программе.
