## 📌 Номер и условия вариантов
* **Задание №3** (Базовый уровень): Генератор приветствий. Модуль greetings.js экспортирует 3 функции формирования приветствий; UI переключает шаблон.
* **Задание №9** (Средний уровень): Корзина покупок. cart.js вычисляет сумму, products.js содержит каталог, ui.js отображает позиции.
* **Задание №19** (Повышенный уровень): Доска Kanban. Модули tasks.js, columns.js, storage.js, ui.js: карточки и переходы между статусами.

---

## 🎯 Цель работы
Научиться организовывать клиентское JavaScript-приложение в виде отдельных файлов и ES-модулей, разделять ответственность компонентов, экспортировать и импортировать функции и данные (named/default exports), тестировать взаимодействие модулей и отделять бизнес-логику от операций с DOM.

---

## ⚙️ Входные и выходные данные

### Задание №1 (Базовый уровень):
* **Входные данные:** Выбор шаблона приветствия в UI и ввод имени пользователя.
* **Выходные данные:** формированная строка приветствия из соответствующей функции модуля greetings.js
  
### Задание №2 (Средний уровень):
* **Входные данные:** Список товаров из products.js, действия пользователя по добавлению/удалению товаров в UI.
* **Выходные данные:** Динамическая отрисовка списка через ui.js и итоговый расчёт стоимости в cart.js.
  
### Задание №3 (Повышенный уровень):
* **Входные данные:** Данные карточек задач (название, описание, приоритет, исполнитель), перетягивание (Drag & Drop) или клики для смены статуса колонки.
* **Выходные данные:** Обновление структуры колонок (columns.js), управление состоянием задач (tasks.js), сохранение состояния в localStorage (storage.js) и обновление UI (ui.js).

## 🛠️ Алгоритм решения
1. **Создание структуры директорий styles/, src/ и src/modules/. Подключение главного скрипта с атрибутом type="module" в index.html** Создание структуры директорий styles/, src/ и src/modules/. Подключение главного скрипта с атрибутом type="module" в index.html
2. **Разработка бизнес-логики и данных:** Реализация автономных JS-файлов без привязки к DOM (использование именованных экспортов export function ... / export const ...).
3. **Реализация DOM-интерфейса и связи модулей:** Импорт необходимых функций (import { ... } from './modules/...') в main.js и ui.js, навешивание обработчиков событий addEventListener().
4. **апуск и проверка:** Локальный запуск через HTTP-сервер (python -m http.server или extension Live Server) для предотвращения CORS-ошибок при загрузке ES-модулей.
