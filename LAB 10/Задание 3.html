В: В чем главное отличие ES-модулей от обычных JS-скриптов?

ES-модули имеют собственное изолированное область видимости (Scope), выполняются всегда в строгом режиме ('use strict'), загружаются асинхронно и требуют явного объявления экспорта/импорта.

В: Зачем указывать attribute type="module" в HTML?

Атрибут сообщаю браузеру, что скрипт содержит директивы import и export, откладывает выполнение до загрузки DOM (deferred по умолчанию) и включает CORS-проверки.

В: Именованный экспорт (Named) vs Экспорт по умолчанию (Default)?

Named export (export const task = ...) позволяет экспортировать несколько сущностей и требует точных имен в { } при импорте. Default export (export default ...) экспортирует одну сущность на файл.

В: Зачем отделять бизнес-логику от DOM-операций?

Это обеспечивает паттерн MVC/Separation of Concerns. Модули задач и вычислений легко тестировать автотестами без надобности эмулировать элементы браузера (DOM).
