# 📊 ОТЧЕТ ПО ЛАБОРАТОРНОЙ РАБОТЕ №9
> **Тема:** Асинхронные запросы (Fetch API, AJAX): получение данных с публичного REST API и отображение на странице   
> **Выполнил:** Мальков Александр / ИС 25 22  
> **Среда разработки:** Visual Studio Code / HTML5, CSS3, JavaScript (ES6), JSONPlaceholder API
---

## 📌 Номер и условия вариантов
* **Задание №3** (Базовый уровень): Показать 10 задач /todos; выделять выполненные задачи визуально.
* **Задание №9** (Средний уровень): Загрузить задачи /todos и добавить фильтр: все / выполненные / невыполненные.
* **Задание №19** (Повышенный уровень): Сделать поиск публикаций с задержкой ввода (debounce) и отменой предыдущего запроса через AbortController..

---

## 🎯 Цель работы
Освоить отправку асинхронных HTTP-запросов из браузера с помощью функции fetch(), получение данных публичного REST API, преобразование JSON и динамическое отображение результатов в DOM. Научиться обрабатывать сетевые ошибки, проверять статус response.ok, управлять состояниями загрузки и безопасно выводить данные.

---

## ⚙️ Входные и выходные данные

### Задание №3 (Базовый уровень):
* **Входные данные:** Запрос к эндпоинту [https://jsonplaceholder.typicode.com/todos?_limit=10](https://jsonplaceholder.typicode.com/todos?_limit=10)
* **Выходные данные:** Список из 10 задач с визуальным разделением выполненных (completed: true) и невыполненных (completed: false) элементов.
  
### Задание №9 (Средний уровень):
* **Входные данные:** Полный массив задач из /todos, выбор пользователя в переключателе фильтра (все, выполненные, невыполненные).
* **Выходные данные:** Динамическая фильтрация и отрисовка списка задач в интерфейсе в соответствии с выбранным критерием.
  
### Задание №19 (Повышенный уровень):
* **Входные данные:** Ввод текстовых символов в поле поиска публикаций с задержкой ввода (debounce), отправка запроса и управление жизненным циклом предыдущего запроса через AbortController.
* **Выходные данные:** Актуальные результаты поиска публикаций в реальном времени без избыточных сетевых запросов и конфликтов старых ответов.

---

## 🛠️ Алгоритм решения
1. **Разметка интерфейса (HTML5):** Создание элементов управления (кнопки загрузки, селекты фильтров, поле ввода поиска) и контейнеров для вывода динамических данных.
2. **Оформление и интерактивность (CSS3):** Разработка современного интерфейса с индикаторами загрузки, стилизацией статусов задач и адаптивной версткой.
3. **Логика JavaScript и Web Storage:**
   * **Вариант №3:** Использование fetch(), async/await, проверка флага response.ok, безопасная вставка данных через textContent.
   * **Вариант №9:** Реализация интерактивного переключения состояния фильтрации массива задач на клиенте.
   * **Вариант №19:** Реализация механизма debounce с помощью таймеров и предотвращение гонки запросов через объект AbortController.

## 🎯 Вывод
В ходе выполнения лабораторной работы были успешно освоены принципы работы с асинхронными сетевыми запросами с использованием Fetch API, функции fetch() и синтаксиса async/await. На практике изучены методы разбора JSON-ответов, проверки свойства response.ok, а также безопасного перехвата сетевых ошибок с помощью конструкций try...catch. Реализованы продвинутые интерактивные сценарии: клиентская фильтрация данных, управление отменой актуальных запросов через AbortController и оптимизация ввода текста с помощью паттерна debounce.
