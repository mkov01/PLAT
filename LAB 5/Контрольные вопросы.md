16. Для чего используется JavaScript в браузере?
JavaScript используется для создания интерактивных и динамических веб-страниц. Он позволяет оживить статичный HTML-код: обрабатывать клики пользователя, отправлять запросы на сервер без перезагрузки страницы (AJAX), изменять содержимое и стили элементов на лету, а также валидировать вводимые данные в формах.

17. Чем let отличается от const?
• let используется для объявления переменных, значение которых можно изменить (переприсвоить) в дальнейшем коде.
• const используется для объявления констант, значение которых нельзя изменить после инициализации.
• Примечание: Оба ключевых слова имеют блочную область видимости, но если в const записан объект или массив, их внутренние свойства/элементы изменять можно, нельзя лишь перезаписать саму переменную целиком.

18. Что такое условный оператор?
Условный оператор (например, if, if...else, switch) — это управляющая конструкция кода, которая позволяет выполнять различные блоки команд в зависимости от истинности или ложности определенного условия (логического выражения).

19. Какие циклы есть в JavaScript?
В JavaScript существуют следующие основные циклы для многократного повторения кода:
• for — классический цикл со счетчиком.
• while — цикл с предусловием (выполняется, пока условие истинно).
• do...while — цикл с постусловием (гарантированно выполнится хотя бы один раз).
• for...of — цикл для перебора значений итерируемых объектов (например, элементов массива).
• for...in — цикл для перебора свойств объекта.

20. Что такое функция и параметр функции?
• Функция — это именованный, изолированный блок кода, который можно вызывать многократно из разных мест программы для выполнения конкретной задачи.
• Параметр функции — это переменная, указанная при объявлении функции, которая служит «входным карманом» для получения внешних данных (аргументов) при её вызове.

21. Что такое DOM?
DOM (Document Object Model) — это объектная модель документа, которая представляет HTML-структуру веб-страницы в виде дерева объектов. Благодаря DOM, язык JavaScript получает полный доступ к тегам, атрибутам и стилям страницы и может ими управлять.

22. Как получить HTML-элемент в JavaScript?
Для этого используются специальные методы глобального объекта document:
document.getElementById('id') — поиск по уникальному идентификатору.
document.querySelector('.class' или '#id') — универсальный и самый популярный метод поиска первого элемента по CSS-селектору.
document.querySelectorAll('.class') — нахождение всех подходящих элементов (возвращает коллекцию NodeList).

23. Чем textContent отличается от value?
• textContent считывает или изменяет текстовое содержимое обычных HTML-тегов (например, <div>, <span>, <h1>), игнорируя HTML-разметку внутри них.
• value используется для получения или изменения текущего значения полей ввода (элементов форм, таких как <input>, <textarea>, <select>).

24. Что такое событие?
Событие — это сигнал от браузера о том, что на странице произошло определенное действие. События могут генерироваться пользователем (клик мыши, нажатие клавиши, скролл страницы) или самим браузером (окончание загрузки документа, ошибка сети).

25. Для чего используется addEventListener()?
Метод addEventListener() используется для регистрации обработчика события на конкретном HTML-элементе. Он связывает тип события (например, 'click') и функцию, которая должна автоматически выполниться, когда это событие произойдет.

26. Как добавить или удалить CSS-класс через JavaScript?
Для этого используется свойство classList HTML-элемента:
• element.classList.add('имя_класса') — добавляет класс.
• element.classList.remove('имя_класса') — удаляет класс.
• element.classList.toggle('имя_класса') — переключает класс (удаляет, если он есть, и добавляет, если его нет).

27. Как создать HTML-элемент средствами DOM?
Процесс создания состоит из двух обязательных шагов:
1. Создание самого элемента в памяти браузера: const newDiv = document.createElement('div');
2. Физическое добавление элемента в DOM-дерево страницы с помощью методов вставки, например: parentElement.appendChild(newDiv) или parentElement.append(newDiv).
