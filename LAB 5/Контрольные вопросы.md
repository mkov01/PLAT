## 🛠 Контрольные вопросы и ответы

<details open>
<summary><b>16. Для чего используется JavaScript в браузере?</b></summary>
<br>

JavaScript используется для создания **интерактивных и динамических веб-страниц**. Он оживляет статичный HTML-код, позволяя:
* Обрабатывать действия пользователя (клики, ввод текста, движения мыши).
* Изменять содержимое тегов и CSS-стили элементов на лету без перезагрузки страницы.
* Отправлять фоновые запросы на сервер и обновлять данные (AJAX).
* Валидировать формы на стороне клиента перед отправкой.
</details>

<details>
<summary><b>17. Чем let отличается от const?</b></summary>
<br>

Обе переменные имеют блочную область видимости, но имеют ключевое различие в поведении:

| Ключевое слово | Переприсваивание значения | Пример использования |
| :--- | :--- | :--- |
| **`let`** | **Разрешено**. Значение переменной можно перезаписать в процессе выполнения программы. | Изменяемый счетчик, флаг состояния. |
| **`const`** | **Запрещено**. Переменная объявляется один раз и не может быть перезаписана. | Ссылка на DOM-элемент, конфигурация, константа математики. |

> ⚠️ **Важно:** Если в `const` записан объект или массив, их внутренние свойства/элементы изменять *можно*, нельзя лишь перезаписать саму переменную целиком другим значением.
</details>

<details>
<summary><b>18. Что такое условный оператор?</b></summary>
<br>

**Условный оператор** (например, `if`, `if...else`, `switch`) — это базовая управляющая конструкция, которая направляет ход выполнения программы. Она позволяет выполнять определенные блоки кода только в том случае, если заданное логическое условие является истинным (`true`).
</details>

<details>
<summary><b>19. Какие циклы есть в JavaScript?</b></summary>
<br>

В JavaScript используются следующие конструкции для многократного повторения кода:
* `for` — классический цикл со счетчиком (используется, когда известно точное число итераций).
* `while` — цикл с предусловием (выполняется до тех пор, пока условие истинно).
* `do...while` — цикл с постусловием (код внутри гарантированно выполнится хотя бы один раз перед первой проверкой).
* `for...of` — современный цикл для последовательного перебора значений итерируемых объектов (массивов, строк).
* `for...in` — специальный цикл для перебора всех перечисляемых свойств (ключей) объекта.
</details>

<details>
<summary><b>20. Что такое функция и параметр функции?</b></summary>
<br>

* **Функция** — это изолированный, именованный блок кода, спроектированный для решения конкретной подзадачи. Его можно вызывать («запускать») сколько угодно раз из любого места программы.
* **Параметр функции** — это локальная переменная, указываемая в круглых скобках при объявлении функции. Она служит для приема внешних данных (аргументов) в момент вызова.
</details>

<details>
<summary><b>21. Что такое DOM?</b></summary>
<br>

**DOM (Document Object Model)** — это объектная модель документа, сгенерированная браузером. Она представляет всю иерархию HTML-страницы в виде интерактивного дерева объектов, где каждый тег, атрибут или кусок текста является отдельным «узлом» (Node). JavaScript использует DOM как API для управления структурой и контентом страницы.
</details>

<details>
<summary><b>22. Как получить HTML-элемент в JavaScript?</b></summary>
<br>

Для поиска элементов в DOM-дереве используются специальные встроенные методы объекта `document`:
```javascript
// Поиск по ID (самый быстрый, возвращает один элемент)
const mainCounter = document.getElementById('counter-output');

// Поиск по любому CSS-селектору (возвращает ПЕРВЫЙ совпавший элемент)
const activeInput = document.querySelector('.card input[type="text"]');

// Нахождение ВСЕХ элементов по CSS-селектору (возвращает коллекцию NodeList)
const allButtons = document.querySelectorAll('.btn-action');
```
</details>

<details>
<summary><b>23. Чем textContent отличается от value?</b></summary>
<br>

Оба свойства используются для извлечения данных из DOM-узлов, но работают с принципиально разными типами элементов:
* **`textContent`** — используется для чтения или изменения текстового содержимого внутри парных HTML-тегов (таких как `<div>`, `<span>`, `<p>`, `<li>`). Браузер полностью игнорирует HTML-теги внутри и оперирует чистым текстом.
* **`value`** — используется для получения или обновления текущих данных, введенных в **интерактивные элементы форм** (`<input>`, `<textarea>`, `<select>`).
</details>

<details>
<summary><b>24. Что такое событие?</b></summary>
<br>

**Событие** — это официальное уведомление (сигнал) от браузера о том, что в системе или на странице произошло определенное действие. События делятся на:
* *Пользовательские:* клик мыши (`click`), нажатие клавиши (`keydown`), отправка формы (`submit`), прокрутка экрана (`scroll`).
* *Системные:* завершение загрузки страницы (`DOMContentLoaded`), потеря сетевого соединения, ошибка загрузки скрипта.
</details>

<details>
<summary><b>25. Для чего используется addEventListener()?</b></summary>
<br>

Метод **`addEventListener()`** предназначен для регистрации **слушателя события** на конкретном DOM-элементе. Он сообщает браузеру: *«когда на этом элементе произойдет указанное событие (например, клик), автоматически запусти вот эту функцию»*. Это позволяет подвязывать логику к интерфейсу, не смешивая JS с HTML-кодом.
</details>

<details>
<summary><b>26. Как добавить или удалить CSS-класс через JavaScript?</b></summary>
<br>

Управление стилями элементов на профессиональном уровне происходит через работу со свойством **`classList`**:
```javascript
const taskRow = document.querySelector('.list-item');

taskRow.classList.add('active');       // Гарантированно добавляет класс
taskRow.classList.remove('pending');   // Удаляет указанный класс
taskRow.classList.toggle('completed'); // Переключает класс (удалит если есть, добавит если нет)
```
</details>

<details>
<summary><b>27. Как создать HTML-элемент средствами DOM?</b></summary>
<br>

Процесс создания и вывода элемента на экран всегда состоит из двух обязательных шагов:
1. **Создание в памяти:** `const newListItem = document.createElement('li');`
2. **Внедрение в структуру страницы:** Чтобы элемент появился на экране, его нужно встроить внутрь существующего родительского контейнера методами `append()`, `prepend()` или `appendChild()`:
```javascript
const listContainer = document.getElementById('todo-list');
listContainer.append(newListItem); // Добавляет новый элемент в самый конец списка
```
</details>

<details>
<summary><b>28. Как перебрать массив с помощью цикла?</b></summary>
<br>

Существует несколько подходов. В современной разработке чаще всего применяются два метода:
* Использование лаконичного встроенного метода массива **`.forEach()`**:
```javascript
const items = ['Молоко', 'Хлеб', 'Яблоки'];
items.forEach((item, index) => {
    console.log(`Товар №${index + 1}: ${item}`);
});
```
* Использование современного цикла **`for...of`**:
```javascript
for (const item of items) {
    console.log(item);
}
```
</details>

<details>
<summary><b>29. Почему проверка пользовательского ввода важна?</b></summary>
<br>

Валидация (проверка данных) на стороне клиента критически важна для:
1. **Улучшения UX (Пользовательского опыта):** Интерфейс мгновенно реагирует на ошибки ввода (пустое поле, некорректный email, короткий пароль) и помогает пользователю исправить их сразу, не заставляя ждать ответа от сервера.
2. **Оптимизации ресурсов:** Снижает количество лишних бессмысленных сетевых запросов к серверной части приложения.
3. **Первичной безопасности:** Удаление пробелов (`.trim()`) и фильтрация строк предотвращают случайные сбои в работе JS-скриптов.
</details>

<details>
<summary><b>30. Как разделение HTML и JavaScript улучшает структуру проекта?</b></summary>
<br>

Следование архитектурному принципу **«Разделение обязанностей» (Separation of Concerns)**, когда структура (HTML), стили (CSS) и поведение (JS) находятся в раздельных файлах, дает следующие преимущества:
* **Читаемость:** Код становится чистым, понятным и структурированным.
* **Масштабируемость:** Скрипты из отдельных файлов можно легко подключать к разным страницам сайта повторно.
* **Удобство командной работы:** Один разработчик может верстать HTML-каркас, а другой параллельно писать JS-логику в своем файле, не мешая друг другу.
* **Простая отладка:** Ошибки локализуются значительно быстрее, так как логика изолирована от разметки.
</details>
