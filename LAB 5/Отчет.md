## Номер и условия вариантов
**Задание №3** (Базовый уровень): Счетчик кликов. Требуется реализовать графический интерфейс с кнопками «+», «-» и «Сброс». Текущее значение числового счетчика должно динамически отображаться и обновляться в DOM-дереве страницы.
**Задание №10** (Средний уровень): Список покупок. Требуется разработать модуль добавления элементов в список из текстового поля ввода. Элементы должны автоматически нумероваться средствами структуры документа. Необходимо реализовать кнопку полной очистки списка.

## Входные и выходные данные

### Задание №3 (Базовый уровень):
* **Входные данные:** Действия пользователя (события click) по интерактивным кнопкам увеличения, уменьшения или сброса значения.
* **Выходные данные:** Динамическое изменение текстового содержимого (textContent) числового блока на экране, а также динамическая смена цвета шрифта в зависимости от знака числа (зеленый для положительных, красный для отрицательных).

### Задание №10 (Средний уровень):
* **Входные данные:** Текстовая строка из поля ввода (название товара). Событие клика на кнопку «Добавить» или нажатие клавиши Enter.
* **Выходные данные:** Появление нового упорядоченного элемента внутри нумерованного списка на странице. При клике на кнопку «Очистить» — полное обнуление структуры списка.
* 
### Задание №16 (Повышенный уровень):
* **Входные данные:** Текстовая строка с описанием задачи. События клика по кнопкам управления состоянием конкретной задачи (✔ и ✖).
* **Выходные данные:**• Динамическое добавление блочного элемента задачи. Переключение CSS-класса .completed (зачеркивание текста и изменение прозрачности) при отметке выполнения. Мгновенное обновление счетчиков «Выполнено: X | Осталось: Y» в подвале карточки.

## Алгоритм решения

1. **Разметка интерфейса (HTML5):**
• Сформировать общую сетку-дашборд (Grid Layout), разделяющую рабочую область на три независимые карточки компонентов.
• Для списков применить семантические теги: <ol> для списка покупок (чтобы обеспечить автоматическую нумерацию браузером) и <ul> для списка задач.
• Использовать HTML5-тег <template> для безопасного и оптимизированного рендеринга повторяющихся элементов списка задач.

2. **Оформление и интерактивные состояния (CSS3):**
• Использовать CSS-переменные (:root) для централизованного управления цветовой палитрой, скруглениями и анимациями интерфейса.
• Описать интерактивные состояния элементов (:hover, :focus) и добавить плавные переходы (transition).
• Реализовать анимацию @keyframes fadeIn для плавного появления новых добавленных элементов.

3. **Сценарии JavaScript-валидации:**
• Изоляция контекста: Обернуть каждый программный модуль в самовызывающуюся функцию (IIFE), чтобы изолировать области видимости переменных и исключить конфликты в глобальном пространстве.
• Модуль счетчика: Создать внутреннюю переменную состояния state. Повесить один общий слушатель кликов на контейнер карточки, перехватывать атрибут data-action кнопки и инкрементировать/декрементировать состояние с последующим вызовом функции render().
• Модуль списка покупок: Реализовать функцию валидации на пустой ввод (.trim()). Динамически создавать текстовые узлы с помощью document.createElement(), исключая уязвимости XSS через прямое присвоение в textContent.
• Модуль списка задач: Применить паттерн делегирования событий. Повесить один слушатель кликов на весь родительский контейнер списка задач <ul>.
•При клике программно определять целевую кнопку через метод .closest(), считывать действие из dataset.cmd (удаление remove() или переключение класса classList.toggle('completed')), после чего запускать функцию пересчета статистики.

<script>
    document.addEventListener("DOMContentLoaded", () => {
        "use strict";

        // ЛОГИКА ЗАДАНИЯ №3 (СЧЕТЧИК)
        (() => {
            const counterContainer = document.getElementById("counter-module");
            const display = document.getElementById("counter-output");
            let state = 0;

            const render = () => {
                display.textContent = state;
                display.style.color = state > 0 ? "var(--success)" : state < 0 ? "var(--danger)" : "var(--text-primary)";
            };

            counterContainer.addEventListener("click", (e) => {
                const action = e.target.dataset.action;
                if (!action) return;
                if (action === "increment") state++;
                else if (action === "decrement") state--;
                else if (action === "reset") state = 0;
                render();
            });
        })();

        // ЛОГИКА ЗАДАНИЯ №10 (СПИСОК ПОКУПОК)
        (() => {
            const input = document.getElementById("shop-input");
            const addBtn = document.getElementById("shop-add-btn");
            const clearBtn = document.getElementById("shop-clear-btn");
            const list = document.getElementById("shop-list");

            const addItem = () => {
                const textValue = input.value.trim();
                if (!textValue) return;

                const li = document.createElement("li");
                li.className = "list-item";
                const textSpan = document.createElement("span");
                textSpan.className = "item-text";
                textSpan.textContent = textValue;

                li.appendChild(textSpan);
                list.appendChild(li);
                input.value = "";
                input.focus();
            };

            addBtn.addEventListener("click", addItem);
            input.addEventListener("keydown", (e) => { if (e.key === "Enter") addItem(); });
            clearBtn.addEventListener("click", () => { list.textContent = ""; });
        })();

        // ЛОГИКА ЗАДАНИЯ №16 (СПИСОК ЗАДАЧ)
        (() => {
            const input = document.getElementById("todo-input");
            const addBtn = document.getElementById("todo-add-btn");
            const list = document.getElementById("todo-list");
            const doneCountEl = document.getElementById("todo-done-count");
            const leftCountEl = document.getElementById("todo-left-count");
            const updateStats = () => {
                const total = list.children.length;
                const completed = list.querySelectorAll(".completed").length;
                doneCountEl.textContent = completed;
                leftCountEl.textContent = total - completed;
};

            const createTodoItem = () => {
const textValue = input.value.trim();
if (!textValue) return;
const li = document.createElement("li");
li.className = "list-item";
const textSpan = document.createElement("span");
textSpan.className = "item-text";
textSpan.textContent = textValue;
const actionWrapper = document.createElement("div");
actionWrapper.className = "item-actions";
const toggleBtn = document.createElement("button");
toggleBtn.textContent = "✔";
toggleBtn.className = "btn-primary btn-action";
toggleBtn.style.background = "var(--success)";
toggleBtn.dataset.trigger = "toggle";
const deleteBtn = document.createElement("button");
deleteBtn.textContent = "✖";
deleteBtn.className = "btn-danger btn-action";
deleteBtn.dataset.trigger = "delete";
actionWrapper.appendChild(toggleBtn);
actionWrapper.appendChild(deleteBtn);
li.appendChild(textSpan);
li.appendChild(actionWrapper);
list.appendChild(li);
input.value = "";
updateStats();
};
list.addEventListener("click", (e) => {
const button = e.target.closest("button");
if (!button) return;
const row = button.closest(".list-item");
const action = button.dataset.trigger;
if (action === "toggle") row.classList.toggle("completed");
else if (action === "delete") row.remove();
updateStats();
});
addBtn.addEventListener("click", createTodoItem);
input.addEventListener("keydown", (e) => { if (e.key === "Enter") createTodoItem(); });
})();
});
