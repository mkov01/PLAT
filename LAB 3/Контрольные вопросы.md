## Ответы на контрольные вопросы по ООП в Python

---

1. **Что такое ООП?**
**Объектно-ориентированное программирование (ООП)** — это методология программирования, в которой программа строится вокруг объектов, объединяющих данные (атрибуты) и поведение (методы). Основные принципы ООП: инкапсуляция, наследование и полиморфизм.

2. **Что такое класс и объект?**
* **Класс** — это шаблон, чертеж или описание будущих объектов. Он задает структуру данных и набор действий.
* **Объект** — это конкретный экземпляр класса, который существует в памяти компьютера и обладает реальными значениями атрибутов.


3. **Чем класс отличается от объекта?**
Класс — это абстрактный концепт (например, чертеж автомобиля), в то время как объект — это осязаемая сущность, созданная по этому чертежу (конкретная машина марки X с определенным цветом). Класс пишется в коде один раз, а объектов на его основе можно создать сколько угодно.

4. **Что такое атрибут и метод?**
* **Атрибут** — это переменная, принадлежащая классу или объекту, которая хранит его состояние или характеристики (например, `name`, `age`).
* **Метод** — это функция внутри класса, которая определяет поведение объекта и позволяет ему выполнять действия или изменять свои данные.
  
5. **Для чего используется `__init__()`?**
Метод `__init__()` (конструктор) используется для автоматической инициализации объекта в момент его создания. Он задает начальные значения атрибутов экземпляра класса.

6. **Что означает `self`?**
`self` — это ссылка на текущий экземпляр класса (на конкретный объект, который в данный момент вызывает метод). Через `self` метод понимает, данные какого именно объекта нужно использовать или изменять.

7. **Как создать объект класса?**
Для создания объекта нужно вызвать класс по имени, передав ему аргументы для метода `__init__`, как при вызове обычной функции.
*Пример:* `s1 = Student("Адиль", 19, "ВТПО")`

8. **Что такое состояние объекта?**
Состояние объекта — это набор текущих значений всех его атрибутов в определенный момент времени (например, текущие имя, возраст и специальность конкретного студента).

9. **Что такое инкапсуляция?**
**Инкапсуляция** — это принцип ООП, который объединяет данные и методы их обработки в одном классе, а также ограничивает прямой доступ к внутренним компонентам объекта извне для обеспечения безопасности данных.

10. **Что означает атрибут вида `__balance` в Python?**
Атрибут с двумя подчеркиваниями в начале (`__balance`) является приватным (скрытым). Python применяет механизм **Name Mangling** (искажение имени), автоматически переименовывая его внутри класса, что защищает его от случайного изменения напрямую извне.

11. **Почему состояние объекта удобно изменять через методы?**
Изменение состояния через методы позволяет:
* Добавить **проверку (валидацию)** данных перед их сохранением (например, проверка длины пароля или положительного баланса).
* Защитить объект от некорректных значений.
* Скрыть внутреннюю сложную логику программы от внешнего кода.
